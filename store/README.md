# Публикация в Google Play

## Что уже готово в проекте
- `targetSdk 36`, `versionCode 1`, `versionName 1.0`, идентификатор `com.rafinad.goals` (после публикации поменять нельзя).
- Release-сборка со сжатием кода (R8) и подписью из секретов GitHub.
- Графика: `icon-512.png` (значок 512×512), `feature-graphic.png` (обложка 1024×500). Перерисовать: `python store/make_art.py store`.
- Политика конфиденциальности: `privacy-policy.md`.

## Шаги
1. **Аккаунт разработчика** — play.google.com/console, разовый взнос $25. Для личного аккаунта Google требует закрытое тестирование: 12 тестировщиков в течение 14 дней перед выпуском в продакшен.
2. **Ключ загрузки (upload key)** — создаётся один раз. Хранить файл и пароли надёжно: без них обновления не выпустить.
   ```
   keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
3. **Секреты GitHub** — репозиторий → Settings → Secrets and variables → Actions:
   - `KEYSTORE_BASE64` — содержимое `upload.jks` в base64 (`base64 -w0 upload.jks`, в PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("upload.jks"))`)
   - `KEYSTORE_PASSWORD`, `KEY_ALIAS` (`upload`), `KEY_PASSWORD`
   
   После этого каждый push собирает `goals-app-release-aab` во вкладке Actions.
4. **Политика конфиденциальности** — нужна публичная ссылка. Разместите текст `privacy-policy.md` на любой странице (Google Sites, GitHub Pages публичного репозитория и т. п.).
5. **Скриншоты** — минимум 2 скриншота телефона (лучше 4–6: День, Календарь, Цели, Финансы).
6. В консоли создать приложение, загрузить `.aab`, заполнить разделы ниже.

## Ответы для анкет консоли
- **Безопасность данных (Data safety):** данные не собираются и не передаются. Шифрование при передаче — не применимо (нет передачи). Удаление данных — через удаление приложения.
- **Реклама:** нет.
- **Возрастной рейтинг (IARC):** насилия, азартных игр, общения пользователей и покупок нет → рейтинг 3+.
- **Целевая аудитория:** 18+ (или 13+), не для детей.
- **Доступ к приложению:** все функции доступны без входа.

# Цели и задачи

Простое Android-приложение: создаёшь цели, внутри каждой — задачи с галочками, прогресс цели считается автоматически. Данные хранятся локально на телефоне.

Стек: Kotlin, Jetpack Compose (Material 3), minSdk 26.

## Запуск
1. Открыть папку в Android Studio.
2. Run ▶ на эмуляторе или телефоне.

Тесты: `./gradlew test`

# Цели и задачи

Android-приложение для дня, целей и денег. Минималистичный дизайн, светлая и тёмная тема.

- **День** — мысль дня, главная цель дня, постулат дня, рабочие и домашние дела. При запуске всплывает «Совет дня».
- **Календарь** — месяц с отметками дней, где есть дела; нажатие открывает день.
- **Цели** — цели с шагами и прогрессом.
- **Финансы** — доходы и расходы, баланс, итоги за месяц.

Звук при отметке задачи выполненной. Данные хранятся локально на телефоне.

Стек: Kotlin, Jetpack Compose (Material 3), minSdk 26.

## Установка на телефон
APK собирается GitHub Actions после каждого push: вкладка Actions → последний запуск → Artifacts → `goals-app-debug`.

## Запуск из Android Studio
Открыть папку, Run ▶. Тесты: `./gradlew test`
